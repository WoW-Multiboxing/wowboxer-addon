## WoWBoxer 1.2.0

Followers take the leader's target, so the wand keeps shooting.

- **Take the leader's target** (Squad page, each follower; on by default): every damage macro of a follower starts with */assist* on the leader. The wand only keeps shooting, and combo points only build, on your own target. Before, the follower's wand fired once and stopped. Turn it off on the Squad page to get the macros as before. The leader never assists.
- The *Wand* squad macro takes the leader's target first, too.
- **Action bar measurement for the WoWBoxer app:** the addon reports where every visible action bar, bag and menu button really is (also when a small window pushed them together), so the app's Auto-fit can pick a UI Scale where every bar fits.
